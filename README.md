One line per entry, 120 characters at most: the funniest voicemail greeting a cat would record. This entry writes a single greeting in the voice of Miso the cat — napping in the box you threw away, and promising to knock your message off a shelf at 4am — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
